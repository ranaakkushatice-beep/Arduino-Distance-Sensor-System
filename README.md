# 📡 Arduino Smart Distance Alert System
This project is an embedded system application that measures distance using an **Ultrasonic Sensor** and provides feedback.

### 🛠 Technologies & Components
- **Language:** C++ (Arduino)
- **Microcontroller:** Arduino Uno
- **Sensor:** HC-SR04 Ultrasonic Sensor
- **Output:** LED / Buzzer

### 📝 How It Works
The system calculates the distance of an object in front of the sensor. If the distance is less than 10 cm, it triggers a visual/audio alert (LED).

### 🚀 Setup
1. Open `distance_sensor.ino` in Arduino IDE.
2. Connect your components as defined in the code pins.
3. Upload to your Arduino board.
